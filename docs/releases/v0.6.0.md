# 忆尘记账 v0.6.0

这一版只做一件事：**把界面上所有的黑框，换成 iOS 26 那种水晶玻璃。**

v0.5.0 的界面是对的，但材质是错的。深灰底 + 深灰卡片 + 一圈细边，
说它是「暗色主题」没错，说它是「玻璃」就有点自欺欺人了 ——
**玻璃得有东西可透**，透出来的要是同一块灰，那它就是块塑料板。

---

## 一、为什么以前的「玻璃」不好看

v0.2.0 就有一个「玻璃质感」的开关，做法是给卡片加 `rgba` 半透明 + `blur()`。
开关确实有用，但打开之后界面反而更闷。原因有三条，一条比一条致命：

### 1. 背后没有东西可透

整站背景是一个纯色 `#0f1216`。卡片的模糊半径再大，透出来的还是 `#0f1216`，
只是模糊了一下。**在纯色上做毛玻璃，等于什么都没做。**

### 2. 透的是「黑」，不是「光」

即使有内容，深色底上的半透明黑块只会让卡片显得更暗、更脏。
iOS 的深色液态玻璃恰恰相反 —— 它是一层**薄薄的白纱**，
白色只用来定形和提亮，真正好看的是背后那些暖冷光透过模糊后的颜色差。

### 3. 半透明把对比度吃掉了

卡片一透，正文和背景就贴在一起了。字还看得见，但读起来费劲。
这不是审美问题，是可读性问题。

## 二、这一版怎么做的

### 先铺一层「有颜色的暗」

新增 `<Ambient />`（`src/components/Backdrop.tsx`），固定在最底层，不参与滚动：

```
左上 琥珀  rgba(255, 170, 72, 0.26)   —— 呼应「忆尘」的旧纸与灯
右上 冷蓝  rgba(78, 148, 255, 0.24)   —— 呼应夜
左下 青绿  rgba(64, 196, 156, 0.17)   —— 一点点生气
右下 紫    rgba(150, 96, 255, 0.14)
```

四团光斑压在焦墨渐变上。它 `position: fixed`，单独成层，滚动时不重绘，
所以对帧率没有影响。

**这是整个效果的前提。** 没有这层颜色，后面所有的模糊都是在糊空气。

### 玻璃只做四件事

`src/styles.css` 里所有面板级元素（卡片、弹层、侧边栏、底部导航、对话框、
忆小尘面板）统一到一组选择器：

| 要素 | 实现 |
| --- | --- |
| 半透明 + 模糊 + 提饱和 | `background: rgba(...) / backdrop-filter: blur() saturate(175%)` |
| 顶部一道内高光 | `box-shadow: inset 0 1px 0 rgba(255,255,255,.2)` |
| 一圈极细的亮边 | `border: 1px solid rgba(255,255,255,.16)` |
| 一层柔和投影 | `box-shadow: 0 18px 44px rgba(0,0,0,.42)` |

全部用 `background` + `box-shadow` 完成，**没有加伪元素、没有加图层**。
元素数量不变，滚动时就没有额外的合成开销。

### 性能上划了两条线

1. **只有「面板级」元素加模糊。** 列表里的每一行不加 ——
   一屏几十行各来一层 `backdrop-filter`，中端安卓机必掉帧。
2. **模糊半径封顶 26px。** 再大在移动端就要开始吃帧率了，
   而视觉上 26px 和 40px 的差别，人眼基本看不出来。

## 三、浅色主题（新的）

这一版第一次有了真正的浅色主题，设置里三选一：**跟随系统 / 深色 / 浅色**。

它**不是把深色反过来**。玻璃在浅色下是「白上加白」：

- 深色靠「白纱提亮」定形，浅色得靠**暗色描边 + 投影**把面板从背景里托起来；
- 深色下越透越好看（背后是深色，透上来的是光），
  浅色下越透越糊（背后是浅色，透上来的是白），所以**两套的透明度公式方向相反**；
- 高光在浅色下几乎看不见，否则会糊成一片。

所以 `--glass-fill-alpha` 在两套主题里是两条不同的 `calc()`：

```css
/* 深色：k=0 → 0.16（接近实心），k=1 → 0.075，k=1.5 → 0.04 */
--glass-fill-alpha: calc(0.16 - 0.085 * var(--glass-k));

/* 浅色：k=0 → 0.9，k=1 → 0.7，k=1.5 → 0.6 */
--glass-fill-alpha: calc(0.9 - 0.2 * var(--glass-k));
```

JS 只负责给一个 `--glass-k`（0~1.5），具体怎么算交给 CSS。

## 四、玻璃强度：一个滑块，不是两个

v0.2~v0.5 有两个滑块：「面板不透明度」和「背景雾化」。
问题是你得试半天才知道这俩怎么配才好看，而且**大部分组合都不好看**。

现在合成一个 **0~150 的「玻璃强度」**：

| 强度 | 效果 |
| --- | --- |
| 0 | 实心面板，`backdrop-filter` 全部关掉，最省性能 |
| 100 | 出厂的水晶质感 |
| 150 | 最通透，模糊和饱和度同时拉满 |

模糊和饱和度都跟着这一个数走，用户不需要理解它们的区别。

**老数据会自动迁移。** 判断逻辑在 `normalize()` 里：

- 老用户开过玻璃（`glassAlpha < 100`）→ 按「越透明 = 强度越高」折算；
- 没开过（`glassAlpha = 100`）→ 直接给新版默认值 100，让他们也能看到新质感。

不会因为升级丢设置，也不会把默认值 100 误解成「用户想要最实的玻璃」。

## 五、顺手清掉的「黑框」

用户截图里指的那些黑框，逐个找出来了：

| 位置 | 原来 | 现在 |
| --- | --- | --- |
| 模式切换轨道（记账 / 日程） | `var(--bg)` 不透明 | `var(--bg-elev-2)` 白纱 |
| 忆小尘输入框 | `var(--bg)` 不透明 | `var(--bg-elev-2)` 玻璃填充 |
| 输入框边框 | `var(--line)` 灰线 | `var(--glass-edge-soft)` 玻璃切边 |
| 底部导航条 | 深灰底 + 顶边线 | 玻璃面板，圆角只留上面两个 |
| 遮罩层 | 纯黑 55% | 半透明 + 6px 模糊 |

另外把**圆角从 14px 提到 20px**。iOS 26 的玻璃件都是大圆角，
14px 的方卡片配半透明材质，看起来像块玻璃砖。

## 六、三种人会被照顾到

### 1. 用老 WebView 的

不支持 `backdrop-filter` 的浏览器，走 `@supports not (...)` 兜底成 96% 不透明的实底。
**可读性优先**，不会出现「透出黑糊糊一片但字看不清」。

### 2. 开了「减少透明度」辅助功能的

`@media (prefers-reduced-transparency: reduce)` 里玻璃退回 97% 实底、关掉模糊。
这不是可选项 —— 有些人对低对比度的半透明面板是读不清的。

### 3. 开了「减少动态效果」的

动画相关的 `prefers-reduced-motion` 分支保持原样，这一版没有动。

## 八、升级注意

- **没有改数据库 schema**，覆盖安装即可
- 外观设置会自动从「不透明度 + 雾化」迁移到「玻璃强度」，不用手动调
- 网页版 Service Worker 缓存名 `v6 → v7`，如果还看到旧界面，刷新一次
- 桌面版如果没变化，确认装的是新版本：`scripts/installed-check.mjs`
