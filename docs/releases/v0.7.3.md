# 忆笺 v0.7.3

> 这一版只做一件事：**把「忆笺」从两个子 App 的名字，升成整个产品的名字。**
>
> 上一版（v0.7.2）改的是字 —— 忆尘换成忆笺。这一版改的是**结构**：
> 原来「忆笺」只是「忆笺记账」「忆笺日程」两个名字的开头，读起来像两个平行产品；
> 现在它是顶上的那一个词，底下挂三样东西。
>
> 忆笺 · 记账、忆笺 · 日程、忆小尘。
> 助手不加前缀 —— 它不是并列的第三个模块，它是这张纸上会说话的那一部分。

---

## 一、为什么还要再改一次

v0.7.2 把名字换掉之后，侧边栏上并排摆着两块：

```
忆笺记账    ← 这块
忆笺日程    ← 那块
```

问题是：**「忆笺」这两个字出现了两次，却从来没有单独出现过。**
一个品牌名如果只在别人的前缀里出现，它就不是品牌名，只是一个共用词根。
用户读完的感觉是「装了两个 App」，而不是「一个 App 里有两个地方」。

v0.7.1 的时候我把侧边栏顶部那块品牌标题删掉了，理由写得很充分：那两行字和下面的 App 名重复。
现在看，删错了 —— 重复的不是「忆笺」两个字，重复的是「一块没有上下关系的平面」。

所以这一版把抬头加回来，并且让两层关系真的立起来：

```
忆笺                    ← 总和名，一枚「忆」字印 + 标语
  忆笺 · 记账           ← 子 App
  忆笺 · 日程           ← 子 App
```

## 二、为什么中间是个「·」

不是「忆笺记账」加个空格，也不是「忆笺 - 记账」。

- **「忆笺记账」**（连写）读起来是一个词，那就还是并列关系，只是换了写法。
- **「忆笺 · 记账」**（间隔号）读起来是「忆笺底下的记账」。间隔号在中文排版里本来就是**层级分隔**的符号，书名号之间的、丛书名与书名之间的，都用它。
- 英文用 `Yijian · Ledger`，日文用 `憶箋 · 家計簿`，三语同一个结构，不各自发明。

## 三、三句标语，各说各的

侧边栏里三行字挨在一起，标语如果重复就很刺眼。所以三块各有一句：

| 位置 | 标语 | 说的是 |
| --- | --- | --- |
| 忆笺 | **所记所行，皆有归处** | 记下的（账）和要行的（日程），都有地方放 |
| 忆笺 · 记账 | 所记皆来路，所忆皆无尘 | 原来的那句，一字没动 |
| 忆笺 · 日程 | 所行皆有期，所至皆有时 | 原来的那句，一字没动 |

忆笺那句是这一版新起的。原来记账用的「所记皆来路，所忆皆无尘」太贴「记账」了 ——
「忆」在里面指的是回看旧账，盖不住日程。所以另起一句能收住三块的，把老的那句留在它本来该在的地方。

## 四、抬头为什么不可点

顶部那块「忆笺」没有 hover 背景、没有圆角卡片、没有边框，点它什么都不会发生 ——
它不是一个按钮，它是一枚抬头。

这是故意的。侧边栏上凡是能点的东西都有卡片感（两块子 App 就是），
所以「没有卡片感」本身就在告诉用户：上面这个是名字，下面两个是能去的地方。
`schedule-check.mjs` 里有一条断言专门盯着这件事：品牌区里不能有 `button` 或 `a`。

「忆笺」现在是整个产品的名字，所以**所有平台上装好之后看到的名字**都改成它：

| 位置 | 之前 | 现在 |
| --- | --- | --- |
| Windows 窗口标题 / 快捷方式 / 控制面板 | 忆笺记账 | **忆笺** |
| macOS 启动台 / Dock / 活动监视器 | 忆笺记账 | **忆笺** |
| Linux 应用菜单 | 忆笺记账 | **忆笺** |
| Android 桌面图标名 | 忆笺记账 | **忆笺** |
| iOS 主屏名 | 忆笺记账 | **忆笺** |
| 网页版标题 / PWA 名 / 添加到主屏幕 | 忆笺记账 | **忆笺** |
| 英文 | Yijian Ledger | **Yijian** |
| 日文 | 憶箋記帳 | **憶箋** |

装到机器上的是整个产品，不是其中一个子 App —— 任务栏和 Alt+Tab 上看到的应该是「忆笺」。

## 六、刻意没有改的东西

和上一版同一条线，一个都没动：

| 没改的 | 值 | 为什么 |
| --- | --- | --- |
| 程序名 / 包名 | `yichen-ledger` | 改了等于换一个 App。Windows 的数据在 `%APPDATA%\yichen-ledger`，改了目录名，老用户的账本、日程、课表会**原地消失** |
| 应用标识 | `com.yichen.ledger` | Android / iOS 的包名。改了在商店里就是另一个应用，老用户收不到更新 |
| 仓库名 | `yichen-ledger` | GitHub 仓库、Pages 地址、Release 下载链接全挂在这上面 |
| 两枚图标 | 水墨「忆」/ 朱印「程」 | 「忆」「记」「程」三个字都还在新名字里，一个像素没动 |
| 备份文件格式 | `app: "yichen-ledger"`、version 3 | 老备份必须还能导入 |

一句话还是那句：**屏幕上看到的都换了，机器里认的那些都没换。**

## 七、升级要注意什么

1. **什么都不用做。** 数据目录、包名、数据库结构一个都没动，装上新版打开就是原来的账本。
2. **快捷方式名会从「忆笺记账」变成「忆笺」**，开始菜单、桌面、Dock 都会跟着变。旧快捷方式在安装新版时会被替换掉。
3. **PWA / 网页版**：缓存名从 `yichen-ledger-v11` 起算，打开时会自动拉新版，不用清缓存。
4. **安装包文件名没变**，还是 `yichen-ledger-0.7.3-win-x64.exe` 这一套（因为程序名是 ASCII 的 `yichen-ledger`）。
5. **导出/导入的文件名**变成了 `忆笺-记账备份-<时间>.json` 和 `忆笺-记账-<时间>.csv`。只是文件名，备份内容一个字没变。

## 九、这一版自己抓出来的一个排版缺陷

做完之后拿三种语言各量了一遍侧边栏，日文和英文出问题了：

```
侧边栏宽 232px
日文品牌区右边界 253px   ← 顶出去 21px，压在主内容区上
日文第一块右边界 242px
```

标语本身设了 `text-overflow: ellipsis`，看着应该会被截断，但它一次都没生效过。
原因是侧边栏是 flex 容器，里面那一层 `.sidebar-inner` 是 flex 子项，
而 **flex 子项默认 `min-width: auto`** —— 它会撑到「最长的那个不换行子元素」的宽度。
容器根本没变窄，所以里面的 `ellipsis` 永远等不到「装不下」那一刻。

修法是给 `.sidebar-inner` 补 `min-width: 0`，让压缩真的发生。补完之后标语确实能截断了，
但截成「記すも行くも、帰…」比换行难看得多 —— 标语是要读的，不是要扫的。
所以最后改成允许折两行（`-webkit-line-clamp: 2` + `text-wrap: balance` 把两行分匀）。

顺带发现两块 App 在英文下一高一矮（70px / 60px），因为第一块标语两行、第二块一行。
给整块定 `min-height: 70px` 而不是给标语定，这样中文界面也不用白留一行。

**这个缺陷只看中文界面是发现不了的** —— 中文三句标语一行都放得下。
所以新增了 `scripts/rail-check.mjs`，把三种语言在桌面和手机两个宽度下各量一遍：
品牌区/两块有没有顶出侧边栏、标语有没有被截断、两块是不是等高、手机上有没有横向滚动。39 条断言。
