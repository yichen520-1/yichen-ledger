# 忆尘记账 v0.3.0

这一版的主题是**「这个 App 不止会记账」**。

v0.2.0 把它做成了一个像样的软件，v0.3.0 开始往里面装第二个东西：**忆尘日程**。
侧边栏底部多了一个开关，按一下，整个工作区从「记账」换成「日程」——
不是多一个页面，是换一套导航、换一套首页，两套东西共用同一个数据库、同一个安装包。

> **数据不会丢。** 数据库从 version(1) 升到 version(2)，只**新增**一张 `events` 表，
> 原来五张表（账目、账户、分类、预算、设置）的索引一个字都没动。
> Dexie 的版本升级是增量的，打开 App 时账目原样保留，只是多出一张空表。

## 一、忆尘日程

### 模式切换

侧边栏底部（桌面端）和底部导航上方（移动端）各有一个切换钮：

| 模式 | 导航 |
| --- | --- |
| **记账** | 记一笔 / 总览 / 统计 / 预算 / 设置 / 账户 |
| **日程** | 日程 / 设置 |

切过去之后整站的导航跟着换，不是「打开一个日程页」。上次停在哪个模式会记住，
下次打开 App 还是那个模式。

有一个细节：如果你在日程模式下点到了记账的某个页面（比如从别处跳进来），
会自动回到日程首页，不会出现「导航写着日程、内容却是统计页」这种怪状态。

### 三种视图

| 视图 | 看什么 |
| --- | --- |
| **月** | 6×7 网格，每格显示当天前几条日程，多了显示「还有 N 项」。点某天跳到日视图 |
| **周** | 7 列，按时段排，一眼看出这周哪几天满、哪几天空 |
| **日** | 当天全部日程，带时间、地点、标签、备注 |

左右箭头翻页（月 / 周 / 日各按自己的粒度），点「今天」回到当前。

### 一条日程能记什么

标题、日期、开始与结束时间、全天开关、地点、标签、颜色（8 种）、备注。

### 重复规则

| 频率 | 可调 |
| --- | --- |
| 不重复 | — |
| 每天 | 每 N 天，重复到某天或一直重复 |
| 每周 | 每 N 周，可多选周几（周一三五、周末都行） |
| 每月 | 每 N 月 |
| 每年 | 每 N 年 |

重复日程里，**每一次发生可以单独勾完成**：今天这次做完了勾上，明天那次还在，
不会因为勾了一次就把整串都标成完成。

### 其他

- **勾选完成**：点前面的圆圈，完成了打勾并淡出
- **搜索**：搜标题、备注、地点、标签，实时过滤
- **删除**：带确认，删重复日程会删整串（会提示）
- 桌面宽度下月视图的格子是固定行高，不会因为主内容区有 900px 就把每个格子
  撑成 120px 高、整月撑出两屏

## 二、从图片建日程

拍一张课程表、会议通知、微信里的时间约定，丢进来让它认。

### 两条路

| 情况 | 走哪条 | 说明 |
| --- | --- | --- |
| 在设置里填了 API Key | **云端多模态** | 认得更准，能理解「下周三下午茶」这种说法 |
| 没填 Key | **本机 OCR** | tesseract.js 在设备上跑，不联网、不上传，慢一点、准确率低一些 |

本机 OCR 的 wasm 和语言包有十几 MB，所以做成了**动态加载**：
不点「从图片建日程」这个按钮，就永远不会下载它，首屏体积一点没变。

### 认出来之后

不会直接写库。识别结果先填进表单，标题、日期、时间、地点各就各位，
你可以改完再保存 —— 猜错了不要紧，它只是个更省事的起点。

如果一条都没认出来，会明说「没从图里认出可用的日程，可以手填」，不会假装成功。

## 三、到点提醒

四端的情况不一样，所以分三条路走，并且在界面上**如实告知**：

| 平台 | 能力 |
| --- | --- |
| **Android / iOS** | 走系统本地通知（`@capacitor/local-notifications`），**App 关着也会弹** |
| **网页版** | 浏览器不给「关掉页面还能提醒」这个权限，所以退化成页面开着时提醒，并明说这个限制 |
| **Windows / macOS 桌面版** | 页面一直活着，页面内定时就够用 |

提醒可选：准时、提前 5 分钟、15 分钟、30 分钟、1 小时、2 小时、24 小时，可多选。

第一次开启会申请通知权限；被拒绝了会提示「可以到系统设置里打开」，不会死循环弹窗。

**所有提醒都在本机排期，不联网、不上报，通知内容只在本机生成。**

## 四、设置里新增的 AI 一组

日程的图片识别、以及 v0.4.0 要来的忆小尘，都需要一个可选的云端通道。
所以设置页新增一组：

| 项 | 说明 |
| --- | --- |
| 服务商 | DeepSeek / OpenAI / 自定义 |
| Base URL | 换服务商时自动填预设值，也可以自己改 |
| 模型名 | 比如 `deepseek-chat`、`gpt-4o-mini` |
| API Key | 密码框，只存这台设备的 IndexedDB，**不上传、不进备份文件** |

**不填 Key 也是完整可用的**：日程图片走本地 OCR，以后忆小尘走本地规则引擎。
填了 Key 才升级成云端，同一个界面无感切换。

## 五、修掉的几个真问题

1. **桌面月视图撑出两屏**：`.sched-cell` 用 `aspect-ratio: 1/1` 做正方形，
   手机 430px 宽时正好 52px 好看，桌面上主内容区 900px 就把每格撑到 120px 高。
   宽屏下改成固定 66px 行高。
2. **搜索扫不到备注和地点**：一开始只比标题，现在标题、备注、地点、标签一起搜。
3. **弹层被底部导航盖住**（v0.2.0 遗留的根因）：切页动画给祖先加了 `transform`，
   带 transform 的祖先会成为 `position: fixed` 的包含块，弹层被关进主内容区那一层，
   z-index 只在里面比较。v0.2.0 已经改成 portal 到 `document.body`，
   v0.3.0 的日程表单、搜索框、OCR 弹层全部走同一个 `Sheet` 组件。

## 六、升级注意

- 装新版本直接覆盖，**不需要先卸载**。
- 第一次打开会比平时慢一点点（Dexie 建新表，通常几十毫秒）。
- 账目、账户、分类、预算、外观设置、语言选择全部保留。
- 网页版换了新的 Service Worker 缓存名（v3 → v4），
  打开后如果还是旧界面，刷新一次就好。
- 想回退到 0.2.0 也可以：`events` 表留着不影响旧版本读取其他表。

## 七、下一步：v0.4.0 忆小尘

日程做完了，下一个是**忆小尘** —— 一个住在 App 里的助手，两个身份：

| | 忆小尘 · 账 | 忆小尘 · 程 |
| --- | --- | --- |
| 管什么 | 钱 | 时间 |
| 入口 | 总览 / 统计页右下角 | 日程页右下角 |
| 能答什么 | 「这个月吃饭花了多少」「哪一类涨得最快」「下个月预算定多少合适」 | 「这周还有几个会」「帮我把周五下午空出来」「提醒我周三交报告」 |
| 能做什么 | 直接建账目、改预算 | 直接建日程、改时间、设提醒 |

实现上走**混合式**：默认本地规则引擎兜底（不填 Key 也能用），
填了 API Key 就自动升级成云端对话，同一个对话框无感切换。
