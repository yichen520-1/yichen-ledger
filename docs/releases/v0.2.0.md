# 忆尘记账 v0.2.0

这一版的主题是**「让这个 App 像正常软件，也像你自己的软件」**。
记账本身没有变，变的是外壳：它终于有了一个像样的设置中心，会说三种语言，
背景、字体、配色都能按自己的喜好摆弄，切换页面也有了 iOS 那种顺滑的手感。

> 数据不会丢。这一版没有改数据库结构，升级之后原来的账目、账户、预算原封不动。

---

## 一、设置中心

以前「我的」页面只有几块按钮，现在它是一个真正的设置页，分成四组：

| 分组 | 里面有什么 |
| --- | --- |
| **通用** | 界面语言、启动页（总览 / 统计 / 预算，打开 App 直接去那一页）、账户与分类管理的入口 |
| **外观** | 字体风格、字号基准、文字颜色、强调色、圆角、面板不透明度、背景雾化，以及三个区域各自的壁纸 |
| **数据** | 「你的账本只在这台设备上」醒目横幅、四项统计、完整备份 / 恢复 / CSV 导出 / CSV 导入 |
| **关于** | 版本号、项目说明、网页版与项目主页链接 |

原来「我的」里的数据备份、危险操作、关于三块内容都完整搬进了新设置页，**功能一个都没少**。

### 那条「只保存在本地」的提示

用户最容易踩的坑是：换电脑、换手机、重装系统之后以为账本跟着账号走了 —— 其实没有。
所以这次在数据组最上面放了一条琥珀色的横幅：

> **你的账本只在这台设备上**
> 没有云端、没有账号、没有上传。所有账目都存在这台设备的本地数据库里。
> 卸载或换设备之前，请先导出一份完整备份 —— 否则这些数据找不回来。

下面还有一行小字重复这件事，按钮就在手边，看到提示就能立刻备份。

## 二、中文 / English / 日本語

- 三种语言**全量翻译**，不是只翻几个菜单标题：总览、记一笔、统计、预算、账户、
  分类、设置，包括所有提示语、确认框、错误信息、空状态文案。
- **首次启动跟随系统语言**：中文系统显示中文，日文系统显示日文，其余一律英文。
- 设置里可以随时手动指定，选择会记住，下次打开还是它。
- 切换语言时 `<html lang>` 也跟着变（中文写 `zh-CN`），朗读器和字体会一起调整。
- 顺带修掉一个隐患：以前数据层抛的错误是硬编码中文，英文界面下会从提示条里
  突然冒出一句中文。现在数据层只抛**错误码**，句子由界面翻译 ——
  这条改动看着小，但它决定了「三语」是不是真的三语。

日文版的名称是「憶塵記帳」，标语译作「記すは来し方、憶うは塵なきこと」，
英文版的标语是「Every entry a path, every memory unmarred」。

## 三、外观自定义

### 三个区域，各自独立

侧边栏、主内容区、底部导航是**三块分开的背景**，可以各放各的图。
比如：主内容区放一张远山，侧边栏保持纯色，底部导航半透明 —— 完全随你。

### 每块背景能调什么

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| 模糊 | 0 ~ 30px | 让照片退成氛围，文字更清楚 |
| 亮度 | 20% ~ 160% | 太暗的图可以提亮 |
| 对比度 | 40% ~ 180% | |
| 饱和度 | 0% ~ 200% | 拉到底是黑白 |
| 水平 / 垂直位置 | 0% ~ 100% | 决定图从哪里开始显示 |
| 缩放 | 100% ~ 200% | |
| 透明度 | 10% ~ 100% | |
| 暗化 | 0% ~ 90% | 在图上压一层深色，保证文字可读 |
| 适配方式 | 覆盖 / 填充 / 居中 / 拉伸 | |
| 水平翻转 | 开 / 关 | |

还有两个省事的按钮：**应用到三个区域**（一次铺满）和**重置本区域**。

### 全局的字体与配色

- **字体风格**：系统默认 / 宋体（衬线）/ 楷体（带毛笔味）/ 圆体。金额数字始终用等宽数字，不会跳。
- **字号基准**：100% ~ 140%。整个界面的字号是按比例缩放的 —— 48 处字号统一改成
  `calc(Npx * var(--font-scale))`，一处调整全站跟着变，布局不会散。
- **文字颜色**：可跟随主题，也可自选。
- **强调色**：默认是琥珀色，可以换成任意颜色（选中态、进度条、按钮都会跟着换）。
- **圆角**：0 ~ 26px，喜欢硬朗就拉到 0。
- **面板不透明度 / 背景雾化**：配合壁纸做「毛玻璃」效果。

这些设置全部存在本地数据库里，和账本同生共死，重启、换页、断网都不会丢。

## 四、iOS 那样的手感

以前切换页面是「瞬间跳」，现在有了方向感：

- **页面横向 push / pop**：按导航顺序前进时从右侧推入，返回时从左侧回来。
- **列表交错淡入**：总览的流水一条条错开 32ms 淡入，不是整块闪烁。
- **按下回弹**：卡片、导航项、分类块、按钮按下时会轻微缩一下（0.97 ~ 0.985）。
- **弹层阻尼上滑**：底部弹层不是线性滑上来，末端有一点回弹。
- **统一的缓动曲线**：`cubic-bezier(.32, .72, 0, 1)`，这是 iOS 的系统级手感。
- **尊重无障碍设置**：系统开了「减少动态效果」时，所有动画自动关掉。

## 五、修掉的两个真问题

### 1. 弹层被底部导航条盖住

切页动画会给内容区加 `transform`，而带 `transform` 的祖先会变成
`position: fixed` 的包含块 —— 弹层的 `z-index: 50` 只在那一层里比较，
外面 `z-index: 30` 的底部导航条反而压在上面，点按钮会点到导航。

**修法**：弹层统一抽成 `Sheet` 组件，用 React portal 挂到 `document.body`，
彻底脱离内容区那一层。顺带补了按 Esc 关闭、打开时锁滚动。

### 2. 英文 / 日文界面里漏出中文

见上面「三语」一节：数据层的错误改成错误码，界面层统一翻译。

## 六、升级注意

- **数据完全兼容**：没有改表结构，装上新版直接打开就是原来的账本。
- **网页版的数据和安装包的数据是两套**（不同域名算不同存储，浏览器规则如此）。
  搬家请用「完整备份」JSON。
- Windows / macOS 首次运行仍会提示「未知发布者」/「仍要打开」，原因是没有代码签名证书，
  和这一版功能无关。
- 程序文件仍然全是 ASCII 英文名（`yichen-ledger`），界面里显示的仍是「忆尘记账」。
