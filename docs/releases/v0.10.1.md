# v0.10.1 · 答非所问

这一版没有新功能。它修的是上一版留下的一个很显眼的问题：**问它一句好，它回你一句日程。**

## 你截图里的那一幕

你在「忆小尘 · 程」里说「你好」，它回「这周没有日程。」

这不是它听不懂「你好」——它压根没机会听懂。日程模式的规则引擎在最后有一句无条件的兜底：认不出来就当成「问这周的日程」。于是「你好」「谢谢」「你是谁」「今天几号」全被答成同一句「这周没有日程」。

账本模式在 v0.10.0 已经有了模糊兜底（`vague`），日程模式一个都没有。这是上一版漏掉的一半。

## 顺着一查，还有六个

修完那一句之后我把两个模式的常见问法逐条跑了一遍，又抓出六个：

**「这周有什么安排」会提议新建一条日程。** 建日程的触发词里有「安排」，没有边界 —— 疑问句和祈使句都被当成了「帮我加一条」，标题还会写成「有什么安排」。现在带疑问词的句子一律不当命令。

**「今天几号」「现在几点」被当成问今天的日程。** 它们问的是日历和时钟，不是安排。现在这两类先让给闲聊。

**「账户余额」不带账户名时答「没听懂」。** 条件里只认「余额/还剩/剩下」，但用户没点名哪个账户时就掉出去了。现在会列出各账户分别多少。

**「现金还有多少」答不出。** 「还有多少」不在关键词里，可这是最自然的说法之一。

**「本周打车都改成交通」只改了一笔。** 批量归类和改一笔的顺序反了，「都改成」里含「改成」，改一笔先接住，只改了最近那一笔 —— 用户以为改了三笔，实际改了一笔。

**批量改一个已经归好的分类，会得到「这句话我没太听懂」。** 更糟的是修好之后它会给一个「确认改这 0 笔」的按钮。现在会说「这几笔本来就都是交通，不用改」，并且不出现按钮。

## 还有一个没被截图暴露的

**填了 API Key 也永远不会走云端。** v0.10.0 在规则引擎里加了 `vague` 兜底之后，「本地算出确定答案才不问云端」这条判断把 `vague` 也算成了确定答案 —— 而 `vague` 的意思恰恰是「我没听懂」，那是最该交给云端的场景。规则引擎现在几乎不返回 `unknown` 了，等于把云端整条路堵死。

## 说错地方时，告诉你去哪儿

在日程模式里说「记一笔午饭 25」，原来回「这句我没太听懂」——可这句话说得完全清楚，只是说错了地方。现在会说「记账在忆笺 · 记账那边」，反过来也一样。

## 这一版抓出来的缺陷

| # | 症状 | 根因 |
| --- | --- | --- |
| 1 | 「你好」回「这周没有日程」 | 日程模式缺闲聊兜底 |
| 2 | 「这周有什么安排」变成新建日程 | 触发词「安排」没有边界，疑问句被当命令 |
| 3 | 「今天几号」回日程 | 时间词闸门抢在闲聊之前 |
| 4 | 「账户余额」答不出 | 只认「余额」，不认「没点名账户」 |
| 5 | 「现金还有多少」答不出 | 关键词缺「还有多少」 |
| 6 | 「都改成」只改一笔 | 批量归类排在改一笔之后 |
| 7 | 已归好的批量给出「改 0 笔」 | 命中集为空时没有单独处理 |
| 8 | 填了 Key 也不走云端 | `vague` 被当成确定答案 |
| 9 | 说错模式时回「没听懂」 | 没有跨模式提示 |

## 数据与升级

数据库、账本、日程、对话记录**一个字都没动**。这一版只改判定逻辑和文案，升级后原有数据原样保留，也不需要迁移。
