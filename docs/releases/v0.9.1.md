# 忆笺 v0.9.1：把手机上的死胡同堵上

这一版没有新功能，只修两个你报上来的问题，外加修图标时顺带发现的第三个。

---

## 一、手机上进得去，出不来

**你看到的现象**：手机上点底部中间那个「+」，进到记账页，然后没有任何地方能退出去——没有返回箭头、没有取消、底部导航条也不见了。

**为什么**：`src/App.tsx` 里有一条规则——记账页不显示底部导航条（`{!isAdd ? <nav className="tabbar">…</nav> : null}`）。这条规则本身没错：记账页底部要放数字键盘，再压一条导航会打架。桌面端没出问题，因为桌面端有侧边栏，随时能点别处走。

问题在于**手机端侧边栏是 `display: none`**。两个「出口」同时不成立，页面就成了死胡同。

**怎么修的**：新做一个 `BackButton` 组件，放在每个次级页面的页头左上角。它读 `window.history.state.idx`：

- 有上一页（`idx > 0`）→ `navigate(-1)`，真的退回去；
- 没有（直接打开这个地址、或者从桌面图标进来的）→ `navigate('/', { replace: true })`，回总览。

用 `navigate(-1)` 而不是一律 `navigate('/')`，是因为从搜索页点进一笔账、再返回，应该回到**搜索结果**，而不是被打回总览——那会让人重新搜一遍。

装到八个页面：记账页、账户、分类、搜索、周期账单、周报、回顾、待收。

统计、预算、设置**没有加**：它们本来就在底部导航条上，随时能点走，页头再放一个返回键只是噪音。

## 二、手机上还有五页根本进不去

修第一个问题的时候顺手查了「手机上到底能到哪些页面」，结果比预想的严重：

| 页面 | 桌面 | 手机 |
| --- | --- | --- |
| 总览 / 统计 / 预算 / 设置 | 侧边栏 ✅ | 底部导航 ✅ |
| 记一笔 | 侧边栏 ✅ | 底部「+」✅ |
| 账户 | 侧边栏 ✅ | ❌ |
| 分类 | 设置页里的链接 ✅ | ❌ |
| 搜索 / 周期账单 / 周报 / 回顾 / 待收 | 侧边栏 ✅ | ❌ |

那五页只在侧边栏里有入口，而手机上根本没有侧边栏。**不是回不去，是压根进不去。**

**怎么修的**：底部导航一共 5 格，塞不下 8 个入口。所以把第 5 格从「设置」换成「更多」，点开是一张从底部弹上来的玻璃抽屉，四列排着：账户、分类、搜索、周期账单、周报、回顾、待收、设置。

设置没有丢——它在抽屉里。换页时抽屉自动收起；桌面端有侧边栏，这一格和抽屉都不出现（`@media (min-width: 900px)` 直接 `display: none`）。

## 三、手机图标和电脑端不是同一张图

**你看到的现象**：手机上「忆笺」的图标是白底、中间一个灰黑的「忆」字、右下角一枚很小的红印——没有山、没有飞鸟。电脑上和网页版的图标是有山有鸟的完整水墨。

**为什么**：图标文件本身没错，错在 Android 8 之后换了图标的拼法。自适应图标是两层叠出来的：

```
<adaptive-icon>
  <background android:drawable="@color/ic_launcher_background" />   ← 纯宣纸色 #F6F1E7
  <foreground android:drawable="@mipmap/ic_launcher_foreground" />  ← 前景层
</adaptive-icon>
```

而 `scripts/make_icon_common.py` 里 `transparent=True` 那一支（专门给前景层用的）只画了「忆」字和那枚朱印，注释写着「山会跟底板撞在一起，去掉」。

这个判断是错的。底板本来就是同一张宣纸的颜色，山画在上面不会撞——真正撞的是**少了山之后，这张图不再像同一张图**。桌面版、iOS、PWA、网页版用的都是完整版，只有 Android 走了残缺的那一支。

**怎么修的**（`scripts/make_icon_common.py` + `scripts/make-icon.py`）：

1. `transparent=True` 不再走单独的简化分支，改成和默认版**画完全一样的构图**，只是底板透明。
2. 前景层原来还把整幅画缩到画布的 62%（所谓「安全区」写法，适合「一个 logo 摆在圆圈中间」）。我们这张是整幅山水，缩到 62% 之后山脚停在 81% 的位置，系统一裁圆，圆的下缘就露出一条硬邦邦的直边——像被切了一刀。改成**铺满整块画布**，让系统遮罩自己裁。

重跑 `make-icon.py` 之后，圆形遮罩和圆角方形遮罩裁出来都和桌面版是同一幅画。

## 四、数据与升级

- **数据库结构一个字段都没动**（还是 version 6），老数据原样可用。
- 设置里那一把应用锁也没动——它存在 `localStorage` 里，这次完全没碰。
- 图标换了，但 **appId / bundle id / 数据目录全都没变**，装新版本不会丢账本，桌面上那个快捷方式会自己换成新图标。
- Android 上如果图标还是旧的，是启动器缓存——把图标从桌面拖掉重新拖一个上去就好。

## 五、自检

新增 `scripts/v091-check.mjs`，**26 条断言**，手机（430×932）和桌面（1280×900）两个视口各跑一遍：

- 手机底部导航第 5 格是「更多」
- 抽屉打得开，八个入口都在
- 从抽屉能进搜索页，进页后抽屉自动收起
- 搜索 / 周期账单 / 周报 / 回顾 / 待收，五个页面手机上都到得了
- 八个次级页面都有返回按钮，点了都能回到总览
- 记账页有返回按钮（就是你报的那个），点得回去
- 直接打开记账页（没有历史记录）也能退出
- 桌面端底部导航是隐藏的、侧边栏齐全、抽屉弹不出来
- 桌面端从侧边栏能进设置页
- 两端都没有控制台错误

## 六、下一步

手机端的导航结构这次算是补齐了，但还留着一个问题：**底部导航只有 5 格，而记账相关的页面已经有十几个**。「更多」抽屉是个应急方案，不是设计。下一版可能值得把「搜索」提到主位置——它是这十几个次级页面里唯一一个高频的。

另外桌面端的托盘和全局快捷键只在 Windows / macOS 上有，Linux 上目前是优雅地不存在。如果有人在 Linux 上用，那里还能再补一次。
