# 忆尘记账 v0.5.0

这一版只做一件事：**让忆小尘能好好聊天。**

v0.4.0 的忆小尘有个很尴尬的毛病 —— 你打字说「你好」，它回你：

> 这句我没太听懂。可以问我：这个月花了多少 / 哪一类花得最多…

一个叫「忆小尘」的东西，第一句话就不认人。这一版把它修好了。

---

## 一、为什么这是个问题

记账 App 里的助手，很容易被做成一个**查询框**：能答数据，但只会答数据。
你问「今天好累」，它查不到「累」这个分类，于是告诉你没听懂。

但助手和查询框的区别恰恰在这一点上：**用户先是在跟一个"人"说话，然后才是在用一个工具。**
第一句话就被弹回去的人，不会问第二句。

所以这一版加了一个**闲聊层**，专门接住「不涉及账本」的话。

---

## 二、现在能聊什么

| 你说 | 它回 |
| --- | --- |
| 你好 / 在吗 | 下午好。今天还顺利吗？（问候随时段变，半夜不会说早上好） |
| 你是谁 | 我叫忆小尘，是「忆尘记账」里的助手。账本和日程的事我都管，别的也能陪你聊两句。 |
| 你能做什么 | 查账 / 记账 / 日程 / 闲聊，四行清单 |
| 今天好累 | 累了就先歇会儿。账明天再记也跑不掉。 |
| 我很难过 | 听着不太好受。想说就说，不想说也没关系，我在这儿。 |
| 烦死了 | 谁惹你了？气归气，别拿钱包出气就行。 |
| 压力好大 | 先别急着把所有事一次想完。捡一件最要紧的，做完再说下一件。 |
| 好无聊 | 无聊的话，要不要看看这个月钱都花哪儿了？比刷手机有意思一点。 |
| 谢谢 / 再见 / 抱歉 | 各有各的回应 |
| 现在几点了 | 现在是 17:41。 |
| 今天几号 | 今天是 2026-10-28，周三。 |
| 12+30等于多少 | 12 + 30 = 42 |
| 讲个笑话 | 有一个（不太好笑，但它是免费的） |
| 嗯 / 好的 | 嗯。还有别的想说的吗？ |
| 随便聊聊 | 好啊。今天怎么样，有什么想说的？ |
| 你在干嘛 | 我就在这儿待着，不累也不困。倒是你，今天过得怎么样？ |

情绪是分种类的：**累、难过、生气、焦虑、开心、无聊、孤单**各有一句，
不是一句「听起来不太好」糊弄所有情况。

## 三、闲聊层不能抢走正事

这是这一版最需要小心的地方。加一层匹配，最容易出的错是**把该做的事抢走**。

举个真实踩到的例子：「好，记一笔午饭 25」——「好」是应答词，
如果应答规则只匹配开头，这句话就变成了一句「嗯。还有别的想说的吗？」，账没记成。

所以三条硬规矩：

1. **闲聊层只在规则引擎返回 `unknown` 之后才跑。** 「这个月花了多少」永远走不到这里。
2. **应答词必须整句匹配。** `^…$`，`好，记一笔午饭 25` 不满足。
3. **记一笔、加日程这类写操作，绝不交给云端用自然语言糊一遍。** 确认按钮是底线。

自检脚本里专门有三条守着这个边界：`好，记一笔午饭 25`、`对，这个月花了多少`、`行，帮我记 30 打车`
都必须返回 null（不算闲聊），继续走原来的规则。

## 四、顺手修掉的三个真 bug

### 1. CSP 把云端 AI 整个拦死了

`index.html` 里的 `connect-src` 写的是 `'self'`。意思是**只许连自己的域名**。
而忆小尘填了 Key 之后要连 `api.deepseek.com` —— 被浏览器策略直接拦掉，
报出来是 `Failed to fetch`。

用户看到的是「云端没答上来（Failed to fetch）」，完全想不到是安全策略的问题。
这个 bug 从 v0.4.0 就在，因为默认不填 Key，一直没暴露。

修法：`connect-src 'self' https: http://127.0.0.1:* http://localhost:*`。
放开 `https:` 是因为模型地址本来就由用户自己填；本机地址留给 Ollama、LM Studio 这类本地网关。

### 2. 没填 Key 也显示「云端」

徽章判断用的是「配置读到了没有」，而不是「有没有 Key」。
结果默认配置（`deepseek-chat`，Key 为空）也会显示成「云端 · deepseek-chat」，
用户以为自己在用云端，其实一直在跑本地规则。

修法：只有 `hasKey(cfg)` 为真才显示云端。现在打开面板，默认是「本地规则」。

### 3. 云端请求没有超时

网络半死不活时 `fetch` 会一直挂着，「正在输入」的三个点转到天荒地老。
现在有 30 秒兜底超时，超时后明确说「等太久了」，退回本地结果。

## 五、自检

新增两个端到端脚本，都在真实浏览器里跑：

**`scripts/chat-check.mjs`（22 项）**
起一个干净的库，记一笔，然后逐句问：打招呼 / 问身份 / 问能力 / 道谢 / 算术 / 报时 / 报日期 /
说累 / 说难过 / 「嗯」/「随便聊聊」/ 查账 / 查分类 / 追问 / 听不懂的话 / 记账确认。
重点验的是**闲聊上来之后，账本功能一个都没坏**，而且「确认前不写库」这条还在。

**`scripts/cloud-chat-check.mjs`（15 项）**
起一个假的 OpenAI 兼容服务，真的走一遍云端链路：
- 填了 Key，徽章变「云端」
- 闲聊和开放问题走云端
- 请求里确实带着账本摘要和前几轮对话
- 数据类问题**仍然本地算**，不发给模型
- 云端返回 500 时，说明原因 + 保住本地答案
- 云端挂了，打招呼照样有人接（不叠技术报错）

单元测试从 87 个加到 **109 个**，其中闲聊层 22 个。

## 六、升级注意

- **没有改数据库 schema**，覆盖安装即可，不用迁移
- 网页版 Service Worker 缓存名 +1，如果还看到旧界面，刷新一次
- **不填 Key 就是完整可用的**：所有闲聊、查账、记账、日程都在本地跑，零网络
- 想接云端：「设置 → AI」，填 Base URL、模型名、API Key。DeepSeek / OpenAI / 自建网关都行
