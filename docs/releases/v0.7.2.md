# 忆笺记账 v0.7.2

> 这一版只做一件事：**改名。**「忆尘」改成「忆笺」。
>
> 记账和日程，说到底都是在记录「已经发生的事」。账记在一张纸上，日子也记在一张纸上 ——
> 所以叫「笺」。笺是小幅的纸，不厚，但能装下一个人一段时间的来路。
>
> 两个 App 现在是 **忆笺记账** 和 **忆笺日程**，助手还叫 **忆小尘**。

---

## 一、为什么改

「忆尘」这个名字是 v0.1.0 时起的。当时只有记账一个功能，名字里的「尘」取的是「尘世」「俗务」的意思 —— 记账确实是俗务，一笔一笔，都是过日子的灰。

但到了 v0.3.0 加了日程、v0.7.0 又加了课表之后，「尘」这个字开始显得轻了。日程和课表不是灰，是**接下来要发生的事**。一个只讲「已经落定的尘」的名字，盖不住一个也在讲「将要来的期」的软件。

「笺」是这个矛盾的一个解：纸是薄的、小的，一张能装下一天的账，也能装下一天的事。它比「尘」重一点，也比「尘」安静。

### 两个图标一个字都没重画

主图标画的是水墨的「忆」字，日程图标右下角的朱印是「程」字。**「忆」和「程」都还在新名字里**，所以 `scripts/make_icon_common.py` 与 `scripts/make_icon_schedule.py` 只改了注释，图一个像素都没动。这次改名的成本因此比想象中低得多。

## 三、刻意没有改的东西

这是这一版最需要说清楚的部分。下面这些**看起来都带「忆尘」，但都不能改**：

| 没改的 | 值 | 为什么 |
| --- | --- | --- |
| 程序名 / 包名 | `yichen-ledger` | 改了等于换一个 App。Windows 的数据在 `%APPDATA%\yichen-ledger`，改了目录名，老用户的账本、日程、课表会**原地消失**（软件会去新目录找，新目录是空的） |
| 应用标识 | `com.yichen.ledger` | Android / iOS 的包名。改了在应用商店里就是另一个应用，老用户收不到更新 |
| 仓库名 | `yichen-ledger` | GitHub 仓库、Pages 地址、Release 下载链接全都挂在这上面。改名会让所有旧链接 404 |
| 部署密钥 | `~/.ssh/yichen_ledger` | 只是文件名 |
| 桌面文件夹 | `D:\Desktop\忆尘记账` | 是磁盘上的真实路径，不是软件的一部分 |

一句话：**屏幕上看到的都换了，机器里认的那些都没换。** 这条线在 v0.1.0 定「程序名 ASCII / 显示名中文」的时候就划好了，这次改名正好验证了它是对的。

---

## 四、升级要注意什么

1. **什么都不用做。** 数据目录、包名、数据库结构一个都没动，装上新版打开就是原来的账本。
2. **快捷方式会变成「忆笺记账」**，开始菜单、桌面、Dock 都会跟着变。旧的那个「忆尘记账」快捷方式在安装新版时会被替换掉。
3. **PWA / 网页版**：缓存名从 `yichen-ledger-v10` 起算，打开时会自动拉新版，不用清缓存。
4. **安装包文件名没变**，还是 `yichen-ledger-0.7.2-win-x64.exe` 这一套（因为程序名是 ASCII 的 `yichen-ledger`）。
