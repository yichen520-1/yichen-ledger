# 忆尘记账 v0.7.1

这一版只改一件事：**侧边栏**。

上一版把「记账 / 日程」从一个胶囊开关改成了两枚图标，方向是对的，
但排布还是不对——两枚 40×40 的小图标并排躺着，上面的品牌标题反而更抢眼，
看起来像「一块 logo + 两个工具栏按钮」。日程页里那两个「日程 / 课表」
胶囊标签也一样：它们挂在页面右上角，点一下换的是整个页面的内容，
位置却在内容区里，像筛选器。

这一版把这些理顺了：

1. **两个 App 竖排，各自带图标、名称、标语**，原来那块品牌标题删掉了。
2. **日程 / 课表 / 设置变成侧边栏菜单项**，不再挂在页面里。
3. **手机底部导航跟着多一项「课表」**，和桌面端对齐。

---

## 一、两个 App 从「并排」改成「竖排」

### 之前为什么不对

上一版的侧边栏从上到下是三块东西：

1. 一块**品牌标题**——水墨标 + 「忆尘记账」+ 「所记皆来路，所忆皆无尘」；
2. 一排**两枚并排的 App 图标**——各 40×40，底下一行 11px 的小字写着 App 名；
3. 一列菜单项。

问题在于：第 1 块和第 2 块里的「忆尘记账」说的是同一件事，却用了两套不同的样子。
品牌块有图标、有名字、有标语，看着最重；而真正用来切换 App 的两枚图标
挤在 194px 里各分到 95px，只能塞下名字，标语根本没地方放。

用户的原话是「我希望的是忆尘日程也和第二个图一样有字和图」——
指的就是品牌块那种「图标 + 名称 + 标语」的排法，希望两个 App 都长成那样。

### 现在长什么样

品牌块删掉，两个 App 各自长成一块「图标 + 名称 + 标语」，上下排：

```
┌──────────────────────────┐
│  ▢  忆尘记账              │  ← 选中：暖色底 + 强调色文字
│     所记皆来路，所忆皆无尘  │
├──────────────────────────┤
│  ▢  忆尘日程              │  ← 未选中：图标压暗到 62%
│     所行皆有期，所至皆有时  │
└──────────────────────────┘
```

- 每块是一行 `flex`：左边 40×40 的图标（圆角 11px，带一层柔和投影），
  右边一列两行字——**名称**（13.5px / 600 字重）在上，
  **标语**（10.5px / 淡色 / 0.05em 字距）在下。
- 选中的那块：底色是 `--accent-soft`、描边 `rgba(255,180,84,0.3)`、名称转强调色。
- 没选中的那块：**只是把图标压暗到 62%**，文字仍然清晰可读，鼠标移上去照样能点。
  为什么不整个压暗：未选中的 App 也是一条正常入口，压到看不清会让人以为它坏了。
- 两块**等宽、撑满侧边栏**（实测各 194px，上下 top 分别是 23 / 89）。
- 标语在两枚 App 上是同一套对仗：`所记皆来路，所忆皆无尘` / `所行皆有期，所至皆有时`。
  这两句在 v0.2.0 / v0.7.0 里就已经是配套的了，只是上一版没地方显示；
  这一版把它们摆到名字底下，对仗才看得出来。

### 品牌标题去哪了

删了。

侧边栏里现在有两块带图标、带名字、带标语的东西，它们本身就是品牌展示。
再在上面压一块 logo + 一行字，等于同一件事说两遍。

> 注意：`.brand` 这套样式本身**保留着**，因为设置页「关于」区块里那枚
> 水墨标（`.brand-mark`）还在用它。删掉的只是侧边栏里那一处。

## 二、日程 / 课表从胶囊标签变成菜单项

### 之前为什么不对

上一版进课表的方式是：日程页右上角两个胶囊「日程 / 课表」，点一下换内容，
地址栏写成 `#/schedule?tab=timetable`。

三个问题：

1. **位置误导**。胶囊在内容区右上角，看起来像「这个列表的筛选条件」，
   但它换掉的是整页内容——包括标题、副标题、操作按钮。这是导航，不是筛选。
2. **它和侧边栏打架**。左边已经有一列菜单，右边又冒出一组平行导航，
   同一个页面里有两套层级。
3. **`?tab=` 不是真路由**。刷新、深链、从通知点回来，都要靠页面自己解析
   query 再纠正，多一道容易出错的环节（v0.7.0 那个「刷新被弹回总览」的 bug
   就是这一带出来的）。

### 现在怎么做

侧边栏在日程模式下是三个平级的菜单项：

```
日程     ← /schedule            （CalendarDays 图标）
课表     ← /schedule/timetable  （Grid3x3 图标）
设置     ← /settings            （Settings2 图标）
```

页面里那两个胶囊删掉了，标题直接写「课表」，副标题显示「第 N 周」。

- **真路由**。`/schedule/timetable` 是 `Route path="/schedule/timetable"`，
  刷新、深链、通知跳转都直接命中，不再需要解析 query。
- **老链接自动跳**。`#/schedule?tab=timetable` 会被一个兼容 effect
  用 `replace: true` 改写成 `#/schedule/timetable`（反向同理），
  所以之前发出去的链接、装好的 PWA 书签都还能用，也不会在历史里留一层空记录。
- **「日程」这一项必须 `end`**。`/schedule/timetable` 是 `/schedule` 的子路径，
  `NavLink` 默认前缀匹配会让两项同时高亮。加了 `end` 之后只有精确匹配才亮。

## 三、手机底部导航也跟着改

桌面端有三个菜单项，手机端只有底部一条 57px 高的导航，装不下五个格子加文字。

这一版手机端在日程模式下是：

```
  日程      课表      设置      ▢
```

三项文字 + 最后一枚**切换 App 的图标**（只放图标不放文字，38×56）。
课表在这里是**和日程并列的第二项**，不是日程的子标签——和桌面端一致。

记账模式下没变，还是「总览 / 统计 / + / 预算 / 设置 / 忆尘日程图标」。

## 四、顺手修的一个假失败

`scripts/chat-check.mjs` 里断言「你好」的回应要包含「在呢 / 你好 / 哈 / 嗨 / 今天」。
但忆小尘的问候是按时间分五档的，深夜那档是：

> 这个点还没睡？我在的，想说什么都行。

里面一个关键词都没有——**这条断言在 23 点之后跑必挂**，白天跑就过。
不是功能坏了，是测试写窄了。这一版把五档问候的共同特征都补进正则
（`在呢|我在的|你好|哈|嗨|今天|早。|中午好|下午好|晚上好`），并加了一行注释
说明为什么要覆盖五档。

## 七、下一步

侧边栏这一块还能再往前走的地方：

- **折叠成图标条**：桌面端窄窗口（< 900px）时收成 56px 的图标栏，悬停出文字，
  把宽度还给内容区。现在 < 900px 直接切成手机布局，中间这一段是空的。
- **拖动排序**：菜单项顺序现在是写死的（日程 / 课表 / 设置），
  记账那边是「记一笔 / 总览 / 统计 / 预算 / 设置 / 账户」。让人自己排会更顺手。
- **侧边栏底部放当月小结**：现在底部只有一行版本号，
  那块空间放「本月支出 ¥X / 预算剩 ¥Y」比版本号有用。
- **App 块的未读角标**：日程里今天还有几条没做，直接在「忆尘日程」那块上标个数字。
